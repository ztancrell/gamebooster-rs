# Research

What other game boosters and tuning guides do, feature by feature, with verdicts and adoption items.
Prose only: vendor code is not kept in this repo.

The same for PGWARE GameBoost (registry-only, nothing worth adopting): [docs/pgware/](pgware/README.md).
The same for Smart PC Utilities' PC Game Booster (temporary Game Mode, loads the WinRing0 driver for sensors): [docs/smartpcutilities-gb/](smartpcutilities-gb/README.md).
The same for Razer Cortex: [docs/razer-cortex/](razer-cortex/README.md).
The same for Hone (server-driven tweak catalogue, encrypted engine, temporary Game Mode): [docs/hone/](hone/README.md).
The same for ISLC, Intelligent Standby List Cleaner (standby purge and timer resolution, both placebo or harmful on Windows 10/11): [docs/islc/](islc/README.md).
The same for ExitLag (relay "ping reducer" with two kernel packet drivers; helps only on a bad ISP route): [docs/exitlag/](exitlag/README.md).
The same for Process Lasso (ProBalance dynamic priority restraint, read from the binary; the basis of `lower_others_mode = "dynamic"`): [docs/process-lasso/](process-lasso/README.md).
The same for JetBoost (BlueSprig, a rebranded IObit booster from 2012; stops a Windows 8-era service list, hard-kills apps, forces min CPU 100 % even on battery; nothing new to adopt): [docs/jetboost/](jetboost/README.md).
The same for Wise Game Booster (permanent XP-era registry tweaks, kills programs, stops services with a resume list; uploads your game list): [docs/wise-game-booster/](wise-game-booster/README.md).
The same for Tier1Suite (Tier1Settings; 43-entry registry/power catalogue with honest notes and real revert, LocalSystem broker that re-applies, no driver; adoption: a Game DVR check in `status`): [docs/tier1suite/](tier1suite/README.md).
The same for BoosterX (Eazfuscator-protected settings manager; its "6.6× less CPU load" CS2 claim is idle-desktop debloat incl. Defender off, worth ~2–3 % FPS; adoption: try a background raw-input throttle): [docs/boosterx/](boosterx/README.md).
The same for IObit Advanced SystemCare 20 (SGB's parent: Turbo Boost is SGB's Boost with the same `.dbd` data and power DLL; ships a WinRing0-derived temperature driver plus WFP, minifilter and registry drivers; "200 %/300 % faster" and "AI Mode" are misleading; adoption: try background Store apps off): [docs/advanced-systemcare/](advanced-systemcare/README.md).
The same for eclean Optimizer (Tauri/Rust, 47 explained persistent tweaks with real undo, demand-start broker, no driver; its gaming tweaks are default-equal or placebo, the Pro Expert ones add heat or remove security; adoption: maybe `WerSvc`/`dmwappushservice` in the services list): [docs/eclean/](eclean/README.md).
The same for AVG TuneUp (Gen Digital, same engine as Avast Cleanup; a cleaner, no game mode left; "Sleep Mode" is persistent startup disabling plus IFEO `Debugger` launch hijacks; always-on service, opt-out telemetry and offers; "79 % quicker startup" / "30 % faster" are unexplained marketing; nothing to adopt): [docs/avg-tuneup/](avg-tuneup/README.md).
The same for Ashampoo WinOptimizer Pro 29 (Delphi suite; Game Booster stops a 12-service list per session with real restart, Live-Tuner priority rules need an auto-start process-notify kernel driver and a LocalSystem service; One Click counts deleted files/cookies as "objects"; Internet Tuner and SSD wizard are placebo or harmful; adoption: maybe `BITS` in the services list): [docs/ashampoo-winoptimizer/](ashampoo-winoptimizer/README.md).
The same for Outbyte PC Repair 2.0 (Auslogics-built; modified Inno installer, program files not unpacked, so read from the file list, setup script and UI strings; three kernel drivers, a second `LhSvc_Setup.exe`, GA4 tracking from the download stub, server-side encrypted scan rules, auto-renewing subscription; "45% faster startup" and Real-Time Boost are misleading or placebo; nothing to adopt): [docs/outbyte-pc-repair/](outbyte-pc-repair/README.md).
The same for Fortect 7.3.5.4 (formerly Restoro; Electron UI over a C++ engine plus Avira's AV engine and up to eight kernel drivers; "Repair N items" counts single cookies, cache files, registry leftovers and each crash event; the "our users" hardware bars are UI constants incl. an 18 °C CPU, and a missing temperature shows as a random 60–65 °C; the crash "fix" is Windows' own `sfc /scannow`; nothing to adopt): [docs/fortect/](fortect/README.md).
The same for Glary Utilities 6.49 (MFC suite, no game booster: "Turbo mode"/"Speed up internet" are dead UI text; Memory Optimizer allocates and frees up to ~2 GB to flush other apps' RAM; pre-ticked CEIP uploads startup-entry metadata over HTTP; 1-Click sums registry history, dead shortcuts and temp files as "issues"; one boot-defrag driver; nothing to adopt): [docs/glary-utilities/](glary-utilities/README.md).
The same for iolo System Mechanic 26.3 (LiveBoost is Process Lasso's ProBalance/SmartTrim/Performance Mode under iolo names; "Ultra Performance" plan, PerfectDisk write filter and NetFilter drivers, RAM-above-50% "issue"; nothing new to adopt): [docs/system-mechanic/](system-mechanic/README.md).
The same for Norton Game Optimizer (Norton 360 26.10 is the Avast engine; "core isolation" pins every non-Windows background process to CPUs 0–1 with SetProcessAffinityMask, plus High priority for the game, High performance plan with core parking off, and Windows Update paused; the game itself is untouched): [docs/norton-game-optimizer/](norton-game-optimizer/README.md).
The same for Microsoft PC Manager 3.23 (Store package; Boost is an all-process working-set trim, or a server-set ISLC-style standby purge, and there is no game mode, power plan or priority code; startup uses Task Manager's StartupApproved flag and services only go to Manual; Deep cleanup preselects the DirectX shader cache; LocalSystem service plus three server-gated kernel drivers (ahflt, ClawFlt, ClawNet), opt-out telemetry including competitor-process uptime; adoption: docs advice not to clear the shader cache before playing): [docs/pc-manager/](pc-manager/README.md).
Open-source tools and guides, read from source, with adoption items:
[GameShift](gameshift/README.md) (per-session apply/revert with a crash journal; mostly folklore tweaks, several of which need a reboot to work),
[valleyofdoom PC-Tuning](pc-tuning/README.md) (measure-first guide; keeps idle states on, prefers per-process timer resolution, silent on Nagle/MMCSS),
[Chris Titus WinUtil](winutil/README.md) (gaming-relevant tweaks only; its Ultimate Performance undo resets all power plans),
[windows-amd-registry-boost](amd-registry-boost/README.md) (one PowerShell script, ~200 AMD driver registry values; mostly Catalyst-era no-ops, the live ones are power/thermal safeguards off that add heat, and its `.reg` restore never deletes what it created; never run it on the Boot Camp 5500M; adoption: maybe a read-only ReLive line in `status`),
[2026 sweep: hellzerg Optimizer/OptimizerNXT and Atlas OS](oss-sweep-2026/README.md) (Optimizer's undo writes fixed values that force HAGS and Game Mode off, NXT has no undo; Atlas is careful and record-and-restore but its gaming tweaks are permanent and placebo or heat/security costs; plus a ranked shortlist of 2024–26 closed-source tools, Lossless Scaling the only GPU-bound-relevant one; adoption: a read-only Fault Tolerant Heap line in `status`, done).
