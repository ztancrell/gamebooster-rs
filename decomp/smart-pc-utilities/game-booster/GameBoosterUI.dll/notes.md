# GameBoosterUI.dll

Forms library (ConfuserEx-protected; names only): `FrmGameModeConfig`, `FrmGameModeEditor` (edit the
service / task / process lists), `FrmGameModeProgress`, `FrmGameModeReport`, `FrmLicMsgBox`,
`FrmLicExpiryReminder`, `FrmLicExpired`, `FrmUpgrade`, `FrmPromotion`, `FrmProgress`,
`FrmExceptionReport` (crash report), light/dark styles, list controls. The licence-expiry reminder,
expired and upgrade forms plus the promotion window are the nag surfaces.
